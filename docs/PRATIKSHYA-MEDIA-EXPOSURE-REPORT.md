## ROOT CAUSE FIXED

Phase 21.4 had built the library but never wired it into the register: `mediaStore.seeded()` mapped only
`SEED_MEDIA` and ignored the imported `getIngestedRecords()`. The result was a register of 26 records with
**zero** ingested assets, so every resolver call fell back to the house manifest plates.

Fix: `seeded()` now merges `SEED_MEDIA` + `getIngestedRecords()` (205 records, 179 ingested), and
`mediaResolver.compareMedia` now ranks real library photography above the old `house` fallback plates and
ranks an explicit usage role (e.g. `CATEGORY_COVER`) above `featured`.
